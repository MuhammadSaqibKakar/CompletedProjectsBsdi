# BSDI Completed Projects Portal

A web-based presentation and reporting portal for browsing completed development-project material by district.

## Overview

The application provides a structured interface for presenting district-level project information and slide-based reporting content through a web experience optimized for fast viewing.

## Key Capabilities

- District-based project presentation browsing
- Slide-preview viewing in the browser
- Administrative publishing workflows
- Persistent application metadata and content storage
- Production-oriented Node.js deployment
- Server-side access controls for protected operations

## 🛠️ Tech Stack

- Node.js
- JavaScript
- Vite
- MySQL
- Server-rendered / API-backed web workflows

## 🔐 Security & Operations

This repository supports an operational project system. Production credentials, administrator access details, database configuration, storage paths, deployment procedures, internal data structures, and security implementation details are intentionally omitted from this public README.

Sensitive environment configuration and project content should remain outside source control and be managed through the deployment platform’s protected configuration and storage facilities.

## Status
